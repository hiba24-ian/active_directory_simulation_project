# Active Directory Simulation Dashboard

A browser-based interface concept that simulates basic directory administration workflows using sample data.

## Interface features
- Example organisational-unit hierarchy
- Sample user records
- User-list filtering by selected organisational unit
- Add-user interface elements

## Run locally
Open `index.html` in a browser. Keep the JavaScript file and image assets in the repository structure.

## Important scope
This is a front-end simulation with in-memory sample data. It does not connect to a real Microsoft Active Directory environment and does not create or manage real accounts.
